// ИМПОРТ СПРАВОЧНИКОВ (CSV)

[ Формат файла ]

Платёжные агенты: code,name,is_resident,is_active,is_own_company
пример: АП,Альфа Пэй,,true,false (код — ключ; существующие обновляются)

Компании-покупатели: name,is_active
пример: МастерТрейд,true

Подразделения: name
пример: Дирекция закупок

Типы документов: code,name,category,is_required_default,recipient_service
пример: ЗКП-09,Акт сверки,purchase,true,Бухгалтерия
category: purchase | payment_agent | payment_bank (можно по-русски: «Закупка», «Платёж через агента», «Платёж через банк»)

Курсы валют: currency,date,rate
пример: USD,2026-10-16,93.76 (код валюты должен существовать)

Импорт добавляет новые записи и обновляет существующие по ключу, но никогда не удаляет: удаление — только вручную на странице справочника.
